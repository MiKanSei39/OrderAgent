# 六合餐厅 OrderAgent

一个基于 LangChain、FastAPI 和 Vue 的智能点餐系统，支持菜单查询、菜品推荐和在线预订。

## 主要功能

- 智能对话：根据口味、忌口和用餐需求推荐菜品。
- 菜单浏览：查看菜品价格、分类、辣度、素食和过敏原信息。
- 菜品推荐：支持按关键词和口味筛选在售菜品。
- 餐厅问答：查询营业时间、地址、电话等常见信息。
- 在线预订：填写人数、时间和座位需求，生成预订并确认下单。
- 订单管理：查看当前会话的预订记录。
- 多轮对话：保留会话内容，支持继续修改预订信息。

## 页面

- 智能助手
- 当季菜单
- 我的预订

## 本地运行

启动后端后访问：

```text
http://localhost:18088
```

根目录提供 `start.bat`，前端目录提供 `ui/start.bat`。项目使用 MySQL 保存业务数据，Redis 和 Milvus 用于 FAQ 与菜品检索。

本项目用于课程作业和本地演示。
